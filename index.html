Setup Guide
How to use JOB Agent AI v3 effectively
1

Get Your Free Gemini API Key

Go to aistudio.google.com/apikey → Sign in with Google → Create API Key → Copy it. It's completely free with 1500 requests/day. Paste it in the Gemini API Key field above and click Save Key.

2

Fill Role, Location, Experience

Enter your target job role (e.g. "SAP SD Consultant"), location (e.g. "Bengaluru"), and years of experience. These are used to build precise filtered search URLs for all 15 portals and for AI suggestions.

3

Click Execute Agent

The agent will: (1) Generate real filtered URLs for all 15 portals, (2) Use Gemini AI to generate tailored resume suggestions per portal, (3) Search for upcoming walk-in drives with verification links, (4) Optionally push everything to Google Sheets.

4

Understanding Walk-in Sources

Each walk-in card shows a 🔍 Verify Source link — this opens a real Naukri/LinkedIn/Google search for that company's walk-in. Always verify before attending. The AI suggests based on patterns; the source link confirms reality.

5

Google Sheets (Optional)

To export to Google Sheets: Create a sheet → Extensions → Apps Script → paste the script below → Deploy as Web App (Execute as: Me, Access: Anyone) → copy URL to config above.

function doPost(e) { try { var sheetUrl = e.parameter.sheetUrl; var action = e.parameter.action; var ss = SpreadsheetApp.openByUrl(sheetUrl); var sh = ss.getActiveSheet(); if (action === 'init') { sh.clearContents(); var headers = ['#','Portal','Search Query','Experience','Location','Search URL','Generated At','Status']; sh.appendRow(headers); var hRange = sh.getRange(1, 1, 1, headers.length); hRange.setFontWeight('bold'); hRange.setBackground('#0a0f1e'); hRange.setFontColor('#00c2ff'); sh.setFrozenRows(1); return ContentService.createTextOutput(JSON.stringify({ok:true})).setMimeType(ContentService.MimeType.JSON); } if (action === 'push') { var rows = JSON.parse(e.parameter.rows); rows.forEach(function(r){ sh.appendRow(r); }); return ContentService.createTextOutput(JSON.stringify({ok:true,msg:rows.length+' rows added'})).setMimeType(ContentService.MimeType.JSON); } } catch(err) { return ContentService.createTextOutput(JSON.stringify({ok:false,msg:err.message})).setMimeType(ContentService.MimeType.JSON); } }
